# Somos Software Web v3.0 — Commercial

Reconstrucción responsive orientada a conversión comercial.

## Flujo
Hero/carrusel → Servicios → Ofertas → Producto propio → Proceso → Contacto → WhatsApp.

## Incluye
- Logo real de Somos Software.
- Carrusel principal con autoplay, flechas, indicadores y swipe táctil.
- Carrusel comercial de ofertas responsive.
- Carrusel del Sistema de Control Financiero.
- Animaciones JavaScript con IntersectionObserver.
- Barra de progreso de lectura.
- Menú móvil.
- SVG para iconografía crítica; evita símbolos Unicode inconsistentes en móviles.
- Diseño responsive y soporte para `prefers-reduced-motion`.

## Antes de producción
1. Configurar `WHATSAPP_NUMBER` en `app.js` con el número WOM comercial en formato internacional, sin `+` ni espacios.
2. Confirmar correo comercial definitivo.
3. Revisar textos/precios y condiciones comerciales.
4. Probar en Android, iPhone y escritorio.
5. Definir dominio definitivo y desplegar.

La web no modifica el Sistema de Control Financiero; enlaza a su demo pública.
